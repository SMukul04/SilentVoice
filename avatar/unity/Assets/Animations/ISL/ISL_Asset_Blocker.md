# ISL Asset Blocker

A genuine ISL animation file could not be legally acquired during this automated phase.

### Target
* **Source:** IIIT-B Indian Sign Language Interpreter project.
* **Requirement:** One valid ISL animation clip (FBX/GLB).

### Blocker
The IIIT-B dataset requires a request/agreement for access, or manual download from the research portal. It cannot be legally fetched via an automated script in this environment without proper authentication and consent.

### Resolution
Per the project guidelines ("generic gesture ≠ ISL sign"), no fake Mixamo gesture or placeholder waving animation has been substituted. 
The animation registry remains empty until a genuine asset is manually imported to this directory.
