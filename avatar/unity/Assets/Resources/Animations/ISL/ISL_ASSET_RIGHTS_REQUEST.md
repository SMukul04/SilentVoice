# SilentVoice - ISL Animation Asset Rights Request

SilentVoice is an Indian Sign Language communication project with:
- ISL-to-text/speech recognition
- speech/text-to-sign processing
- a Unity-based 3D avatar
- a provider-neutral animation architecture

This request is specifically for permission to use selected ISL animation assets in the SilentVoice project.

## Requested Assets

The initial requested signs are:
- PLEASE
- HELLO
- THANK_YOU
- YES
- NO

These are initial integration targets, and the final requested vocabulary may expand later.

## Requested Permission

Does the asset owner/provider permit SilentVoice to:
1. use the animation assets in the SilentVoice project?
2. modify/retarget the assets to the SilentVoice humanoid avatar if technically necessary?
3. redistribute the resulting application containing those animations?
4. publish the project source code containing the necessary non-binary metadata?
5. redistribute the animation binaries if the provider's terms allow it?
6. use the animations in academic demonstrations/presentations?
7. use the animations in publicly accessible builds/demos?

## Licensing Questions

- What license applies to the requested animation files?
- Does the license apply to the animation files themselves or only the source code?
- Is redistribution permitted?
- Is modification/retargeting permitted?
- Is commercial use permitted?
- Is attribution required?
- Are there third-party assets embedded in the animation/model files?
- If third-party assets exist, what licenses apply to them?
- Are there any restrictions on publishing the animations in a public GitHub repository or downloadable application?
- Is there a preferred attribution statement?

## Technical Requirements

SilentVoice currently uses:
- Unity
- humanoid avatar rig
- Unity AnimationClip assets
- sign_id / asset_id separation
- provider-neutral animation resolution

Can the supplied animations be provided in a format compatible with Unity, or is another source format preferred?

## Provenance Evidence Requested

To properly document our compliance, we request one of the following:
- applicable license document

- asset-specific usage terms
- other authoritative documentation establishing redistribution rights

SilentVoice will retain a non-sensitive provenance reference in its repository.
