# SilentVoice Project Context

## Project Name
SilentVoice

## Project Goal
SilentVoice is a real-time communication application intended to help deaf or speech-impaired users communicate through hand gestures/sign language recognition.

## Technologies
- Python
- OpenCV
- MediaPipe
- Machine Learning
- Other existing libraries already present in requirements/code

## Development Rules
- Do not rebuild the project from scratch.
- First understand the existing codebase before making changes.
- Preserve working functionality.
- Make changes incrementally.
- Explain the purpose of every major change.
- When debugging, identify the root cause before changing code.
- Prefer modifying existing files instead of creating unnecessary duplicate files.
- Keep the project beginner-friendly and well structured.

## Current Development Process
1. Analyze existing code.
2. Identify the current working state.
3. Identify incomplete features or bugs.
4. Create a development plan.
5. Implement one feature at a time.
6. Test after each major change.

## Important
Always check the existing implementation before suggesting new architecture.
